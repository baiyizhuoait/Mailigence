Credentials stay encrypted

Passwords and OAuth tokens are sealed with Fernet, and the key lives on your machine — not in a config file you share.

No telemetry

No analytics SDK, no account, no phone-home. The only outbound traffic is the IMAP and AI endpoints you configured.

Any model, or none

Bring DeepSeek, any OpenAI-compatible endpoint, or a local Ollama / LM Studio. Rules-only mode needs no key at all.

Three commands, and it's yours.

Docker 24+ is the only requirement — no Python, Node or PostgreSQL to install. On Windows without Docker, double-click start.bat.

Questions people actually ask

Do I need an AI key to use it?

No. Rules-only mode classifies mail without a model. Add a cloud key, or point it at local Ollama, when you want summaries and reply drafts.

Which mailboxes are supported?

Gmail, Outlook, QQ Mail, 163 and any standard IMAP server. Both app-specific passwords and OAuth2 are supported; SMTP and Microsoft Graph handle sending.

Where does my data live?

In the PostgreSQL database on your own machine. Only the AI requests you configure leave the box — and you can replace them with a local model.

Can I connect my own mailbox to the demo?

No. The public demo is read-only with fictional data, so no visitor's credentials ever land on someone else's server. Self-host to connect a real mailbox — it takes three commands.
